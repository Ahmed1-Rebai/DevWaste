# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion technical, and
do not harass anyone. Unacceptable behaviour can be reported privately to
the maintainer, Ahmed1-Rebai, through GitHub. Reports are handled
confidentially, and the maintainer may remove comments, commits, or issues
that break these rules.
