# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and constructive in issues, pull requests and reviews.
- Critique code and ideas, not people.
- No harassment, insults, or personal or political attacks.
- Do not publish other people's private information.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[@Ahmed1-Rebai](https://github.com/Ahmed1-Rebai), through GitHub. Reports are
handled confidentially. The maintainer may remove comments, commits or other
contributions that break this code, and may block repeat offenders.
